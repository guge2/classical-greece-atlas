# 来源与许可证

本地图集的地理数据来自三个公开数据源，势力归属另据一项古典文献。机器可读的下载记录（含 SHA-256 校验值与获取时间）见 `data/sources.json`；本文件是给人看的说明。

## 一、底图：Natural Earth 1:10m

| 项目 | 内容 |
| --- | --- |
| 来源 | Natural Earth，1:10m Physical Vectors / Raster |
| 下载地址 | `https://naciscdn.org/naturalearth/10m/physical/ne_10m_land.zip`<br>`https://naciscdn.org/naturalearth/10m/physical/ne_10m_minor_islands.zip`<br>`https://naciscdn.org/naturalearth/10m/raster/GRAY_HR_SR_OB.zip` |
| 许可证 | 公共领域（Public Domain） |
| 用途 | 陆地与岛屿多边形（海岸线即多边形边界）、灰度地形阴影 |

Natural Earth 的矢量与栅格数据均属公共领域，可自由使用、修改与再分发，不强制署名。本工程仍在每幅图页脚标注来源。

工程中的处理：按每图范围裁剪 → 轻度预概化（约 100 m）→ 存为 `data/derived/<图 ID>/land.geojson`；地形栅格按每图的兰勃特等角圆锥投影重投影、重采样并量化为 32 级灰度调色板 PNG，最大宽度 1800 像素，以约 12% 不透明度、并被裁剪到陆地范围内叠加。

## 二、古代地点：Pleiades

| 项目 | 内容 |
| --- | --- |
| 来源 | Pleiades: A Gazetteer of Past Places，`https://pleiades.stoa.org/` |
| 下载地址 | `https://atlantides.org/downloads/pleiades/dumps/pleiades-places-latest.csv.gz` |
| 许可证 | **CC BY 3.0** |
| 用途 | 全部 114 个地点的经纬度、地名标题与坐标置信度 |

**署名要求**：Pleiades 数据以 CC BY 3.0 发布，使用时必须署名。本工程的署名出现在三处：每幅地图页脚的来源说明、`data/places.csv` 每行的 `source` 字段（形如 `Pleiades 579885 (CC BY 3.0)`）、以及本文件与 `data/sources.json`。

每个地点保留了 Pleiades ID、原始标题与 `locationPrecision`（`precise` / `related` / `rough`）。`atlas.check` 会把 `places.csv` 中的坐标与转储逐条比对，差异超过 1e-4 度即报错，因此坐标始终可追溯到具体的 Pleiades 条目。

## 三、中文标签交叉核对：Wikidata

| 项目 | 内容 |
| --- | --- |
| 来源 | Wikidata 查询服务，`https://query.wikidata.org/sparql` |
| 许可证 | 结构化数据 CC0 1.0 |
| 用途 | 经属性 P1584（Pleiades ID）关联条目，取其中文与英文标签作交叉核对 |

**Wikidata 标签只用于核对，不会自动覆盖人工译名。** 比对结果写入 `data/derived/wikidata_check.csv`，其中 `matches_zh_name` 一列标明中文主名或别名是否与 Wikidata 中文标签一致。114 条中 112 条关联到 Wikidata，30 条中文主名或别名完全一致；其余差异主要是繁体写法、现代地名或带限定语的条目名。这些差异经人工判定后保留通行的古典译名，原文写入 `zh_aliases` 或 `note`。

据此核对修正的两处音译：

- 瑙帕克托斯（原拟「纳夫帕克托斯」为现代希腊语读法，古典通行译名为瑙帕克托斯）；
- 克尼多斯（原拟「尼多斯」漏译词首辅音，Wikidata 中文标签亦作克尼多斯）。

## 五、字体

使用本机已安装的 **Noto Serif SC** 与 **Noto Sans SC**（`C:/Windows/Fonts/NotoSerifSC-VF.ttf`、`NotoSansSC-VF.ttf`），由 fontTools 实例化为 400/500/600 三个静态字重。Noto 字体族以 SIL Open Font License 1.1 发布。字体文件本身不随工程分发：SVG 中只保留实际用到的汉字轮廓路径，PDF 中只嵌入用到的字形子集，均属 OFL 允许的嵌入用法。
